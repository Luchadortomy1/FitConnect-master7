# FitConnect Assets

This folder contains the app icons and splash screen images.

## Required Assets for Production

- `icon.png` - App icon (1024x1024)
- `adaptive-icon.png` - Android adaptive icon (1024x1024) 
- `splash.png` - Splash screen (1284x2778 for iPhone 12 Pro Max)
- `favicon.png` - Web favicon (48x48)

## Temporary Development Assets

For development purposes, you can create simple placeholder images:
- Use any 1024x1024 image for icons
- Use any large image for splash screen
- Expo will resize automatically

## Creating Assets

You can generate proper assets using:
- Adobe Illustrator/Photoshop
- Figma with icon export plugins
- Online icon generators
- Expo's icon generator tools

The current configuration expects:
- Dark theme splash background: #1A1A2E
- Primary brand color: #00D4AA (teal/green)
